# 📂 Projects

This folder contains mini-projects built while learning JavaScript. Each project focuses on applying core JavaScript concepts (variables, loops, functions, arrays, objects), DOM manipulation, and asynchronous JavaScript in a practical way.

## 🧮 Calculator
A simple calculator app that performs basic arithmetic operations (addition, subtraction, multiplication, division).

**Concepts practiced:**
- DOM manipulation (buttons, display updates)
- Event listeners
- Functions and operators
- Basic input validation

## ✅ To-Do List
A to-do list application that allows users to add, complete, and remove tasks.

**Concepts practiced:**
- Arrays and objects
- DOM manipulation (creating/removing elements dynamically)
- Event delegation
- Local storage (optional persistence)

---

### 🚀 How to Use
1. Open the project folder of your choice.
2. Open the `index.html` file in your browser.
3. Interact with the app to see the JavaScript concepts in action.
